BUILD NOTES · CYBEROS
CyberOS
A small desktop for trying ideas without leaving the browser.
Day 01
The desktop took shape
Built a glassy desktop shell with a real menu bar, dock, and window manager. Every app can move, close, minimize, and return to the foreground.
Day 02
The shell became useful
Added a simulated Linux filesystem and command history. The whole system lives in the browser, so it stays light enough for a tiny host.
Day 03
Network tools, locally minded
Added read-only client-side curl and ping requests plus simulated nmap and dig output for learning workflows.
Day 04
One extra: session recall
Terminal history, theme preference, and notes are remembered in local storage. No account, password, or server database involved.
